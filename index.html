Airdrum
Kamera mati
BPM

Mainkan drum di udara

Nyalakan kamera, lalu ayunkan jari telunjukmu ke bawah di atas zona drum. Kamu juga bisa mengetuk zona, memakai keyboard, atau menyambungkan perangkat MIDI.

Seret zona untuk memindahkan. Scroll di atas zona untuk mengubah ukuran.

Taruh file di folder audio/ (mis. audio/snare-1.wav). Jika file tidak ada, suara sintesis dipakai otomatis. Daftar URL ada di AUDIO_FILES pada script.js.

Klik dua kali pada slider pan untuk mengembalikan ke tengah.

Metronom tidak ikut terekam.

Pukulan terdeteksi saat ujung telunjuk bergerak turun cepat di dalam zona. Naikkan sensitivitas jika pukulan sering tidak terbaca, turunkan jika terlalu mudah berbunyi.

MIDI

Belum tersambung

Klik “Learn”, lalu pukul pad di perangkatmu untuk menetapkan nomor note. Semua channel MIDI diterima.

Keyboard

Klik tombol, lalu tekan tombol keyboard baru. Tekan Esc untuk batal.
